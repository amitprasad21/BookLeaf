## 2. What was built (`backend/src/ai/`)

- **`providers/types.ts`:** the `LlmProvider` contract (per-task `modelFor`) and the `ProviderError` kinds `auth`, `quota`, `rate_limited`, `overloaded`, `timeout`, `connection`, `bad_request`, `refused`, `invalid_output`.
- **`providers/http.ts`:**
  - The single bounded retry layer: 408/429/5xx and connection drops; the provider's delay is honoured up to 5 s; never after a timeout.
  - A retry delay over 60 s is classified `quota`.
- **`providers/gemini.ts`:**
  - Request: `generateContent` with the `x-goog-api-key` header, `responseMimeType` + `responseJsonSchema`.
  - Classification: from `ErrorInfo.reason`, `RetryInfo`, `finishReason` and `promptFeedback.blockReason`.
  - Usage: thinking tokens count as output.
- **`providers/groq.ts`:** OpenAI-compatible chat completions with a strict `json_schema`; classification from `error.code`, 422, 498 and `finish_reason`.
- **`providers/mock.ts`:** responders per schema, plus `[mock:<kind>]` failure markers (never in production).
- **`providers/json-schema.ts`:** zod → JSON Schema for both providers, plus parse-and-validate.
- **`circuit-breaker.ts`:** opens after 3 transient failures; one half-open probe; a failed probe doubles the cooldown (capped at 10 min); held open on configuration errors; `openFor` for quota.
- **`budget.ts`:** daily input + output tokens since 00:00 Asia/Kolkata, a 30 s cache, and local top-up.
- **`router.ts`:**
  - Order: none → budget gate → primary → fallback.
  - No failover on refusal, bad request or invalid output.
  - One `ai_usage_events` row per attempt or skip.
  - `AiRouteError` (503 `AI_UNAVAILABLE`) carries `reason` and `retryable`.
- **`pricing.ts`:** list-price estimates (Gemini 3.8 Flash $0.75/$3.75, 3.5 Flash-Lite $0.30/$2.50, Groq gpt-oss-120b $0.15/$0.075 cached/$0.60).
- **`usage.ts`:** usage write failures are logged and swallowed.
- **`config.ts`:** env → provider plan with per-task model defaults → router.
- **`config/env.ts`:**
  - New AI settings, where empty values and `replace-with…` placeholders count as unset.
  - Production requires `gemini`, `groq` or `none` (never the mock).
  - The fallback must differ from the primary.
  - Each configured provider's key is required outside tests; errors name variables only.
- **`db/system-writer.ts`:** `appendUsageEvent` and `tokensUsedSince` (summed in code: the Data API has aggregates off).
- **Scripts:** `scripts/check-ai.ts` behind `npm run check:ai` / `check:ai:live`.
- **Not wired into requests yet:** triage and drafts call the router in AI-3/AI-4.

The transient overload is the case the router's Groq fallback covers.
