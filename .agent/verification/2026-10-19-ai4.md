## 4. Draft model: measured, then changed

| Configuration | Result |
|---|---|
| Live draft suite, `gemini-3.8-flash` (30 s timeout) | 3 × `timeout` at 30 s; the router failed over to Groq `openai/gpt-oss-120b` each time (success in 2.3–2.4 s, 1,575 in / 770–824 out) |
| Probe: `gemini-3.8-flash`, thinking low, 90 s timeout | no answer within 90 s |
| Probe: `gemini-3.5-flash-lite` | valid draft in 2.2 s (1,389 in / 259 out) |

The failover worked, but 30 s or more per draft is not usable for an admin waiting on screen. The draft default is therefore Flash-Lite (D-030).
