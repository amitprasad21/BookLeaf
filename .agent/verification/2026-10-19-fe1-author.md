# 2026-10-19: FE-1 UI package and the author portal (FE-A1..A4)

Branch `feature/author-portal` (from `main` at `1e9a4bd`). Decision D-031, assumption A-19.

## What was built

- **`packages/ui`** (FE-1): presentation only, with no dependency on `@bookleaf/shared`.
  - `components.css`: component classes built from `tokens.css` tokens only. Tokens added: content widths 1200, 1440 and 800 px. Base link and form-font rules added.
  - Inline SVG icons on a 16 px grid, decorative by default.
  - Primitives: `AppShell` + `NavBar` (skip link, landmarks, a link component passed in so the package needs no Next.js), `PageHeader`, `Panel` (now with actions), `Button` (four variants; the loading state keeps width and focus and ignores clicks), `TextField`/`TextArea` (counter with a polite near-limit announcement)/`Select`/`FileInput`, `Badge`/`StatusBadge`/`PriorityBadge`/`SourceTag`, `ChipGroup`, `Notice`, `EmptyState`/`LoadingState`/`Skeleton`/`ErrorState` (focuses its heading), `KeyFigure(s)`, `ConnectionIndicator`, `MessageThread`, `Disclosure`.
  - Wording comes from callers (labels live in `packages/shared`).
- **`packages/shared`:** display formatters and null wording (`format.ts`), response DTO types (`dto.ts`), and production stages (`production.ts`, moved from the draft facts). The backend serializers now return the DTO types, so the contract is checked at compile time.
- **`author-frontend`:**
  - `lib/`: config, Supabase browser client, API client (bearer token, one refresh-and-retry on 401, then local sign-out to `/login?reason=expired`; error envelope → `ApiError` with `requestId` and `Retry-After`), query client (retry once on network/5xx only).
  - `providers/`: session (`INITIAL_SESSION` → `GET /me` role check; wrong role signs out with the portal-access message; API unreachable → retry screen).
  - Routes: `/login`, `/` → `/books`, `/books`, `/tickets`, `/tickets/new`, `/tickets/[ticketId]`. Unique page titles. Full CSP in `next.config.ts`.
